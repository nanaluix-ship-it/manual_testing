# Портфолио: ручное тестирование

Учебный проект, где основной фокус — на качественной тестовой документации и корректном оформлении дефектов.

## 🌐 Объекты тестирования

- **Веб‑форма**: https://sinsl.github.io/testing-form/  
  Для неё подготовлены тест‑кейсы, чек‑листы и примеры баг‑репортов.
- **Сайт**: https://henderson.ru  
  К нему собран пакет тестовой документации: тест‑кейсы, баг‑репорты.

## 📂 Что есть в репозитории

- `docs/testing-form/` — материалы по форме:
  - тест‑кейсы с предусловиями, шагами и ожидаемыми результатами;
  - чек‑лист для быстрой проверки (smoke/regression);
  - примеры баг‑репортов с указанием окружения, severity и priority.
- `docs/henderson/` — полный пакет по сайту:
  - расширенные тест‑кейсы по ключевым сценариям;
  - баг‑репорты с шагами воспроизведения и скриншотами.

## 📌 Мои навыки в этом проекте

- Тест‑дизайн: позитивные и негативные сценарии, граничные значения, классы эквивалентности.
- Оформление тест‑кейсов: чёткие шаги, однозначные ожидаемые результаты, понятные предусловия.
- Работа с дефектами: описание шагов для 100% воспроизведения, указание окружения, корректная оценка severity/priority.
- Структурирование документации: разделение по объектам и приоритетам, удобная навигация по папкам.
